# CodeSentinel

> AI-powered code intelligence for VS Code.

CodeSentinel is a privacy-focused developer tool that combines semantic code search, project-aware AI, static analysis, security analysis, and AI-powered code review directly inside Visual Studio Code.

The goal is to help developers understand, review, and improve large codebases without constantly switching between their editor and external AI tools.

---

## 🚧 Project Status

**Status:** Early Development

CodeSentinel is currently being developed as a local-first VS Code extension.

### Current focus

- VS Code extension foundation
- Repository indexing
- AST-based code parsing
- Semantic code search
- Local vector database
- RAG-based project understanding

AI code review, security analysis, Git integration, and automated fixes will be added progressively.
